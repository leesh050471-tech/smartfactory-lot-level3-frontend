Next.js 화면입니다. 대시보드(KPI), 수주, 작업지시·실적, 재고, LOT 추적, 품질(AI 불량 분석), 기준정보가 있습니다. 기획서는 `기획서.md`를 보세요. 모든 데이터는 가상입니다.
